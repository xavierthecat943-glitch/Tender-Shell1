# Tender Shell 🖥️

A conversational Linux shell built for Tender OS.

Tender Shell is designed to make the terminal feel less like a command box and more like you're talking to your computer.

## ✨ Features

* 💬 Conversational responses
* 🐧 Linux command support
* ⚙️ Built-in Tender commands
* 🎨 Customizable shell experience
* 🧩 Designed to work independently of Hyprland
* 📦 Arch Linux packaging planned
* 🚀 AUR release planned

## 🎯 Goal

Tender Shell aims to create a terminal where you can use normal Linux commands while also being able to talk naturally to Tender.

For example:

```text
tender@home ~ $ hello

Tender: Hey! 👋
```

Normal Linux commands should continue to work as expected:

```text
tender@home ~ $ ls
Documents  Downloads  Projects
```

## 🛠️ Development

The project will initially be developed and tested on Linux before being packaged for Arch-based distributions.
